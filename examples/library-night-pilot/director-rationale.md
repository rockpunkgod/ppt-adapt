# 夜读试点设计说明

面向公共图书馆管理层，开场直接提出12周、18万元、延时至21点的有界试点。随后依次解释使用情境、模拟需求、备选方案、服务窗口、执行安排，结尾回到具体批准事项。全部数字是原创模拟规划数据，不代表真实调查或客流预测。

浅纸色、墨蓝文字和青绿强调构成共同视觉系统，标题与正文共用统一的中西文字体槽。不同页面分别使用编辑式封面、三栏情境、图表与结论、比较表格、连续时间轴、实施安排和行动清单。第5至6页以已声明的深色变体呈现夜间窗口；页脚身份保持连续。

动效服务解释顺序：第3页按四个时间类别逐次比较两系列，第5至6页用Morph保持时间轴身份，扩展开放窗口。时间轴长度表示小时，不表示需求人次比例；人次覆盖用独立文字说明。其余页面静态，避免无目的的运动。

组合验收包括逐页可编辑对象、文字溢出、数据口径、字体与主题、整套布局节奏、实际点击序列及Morph中间态。还须通过主题强调色变更与深色章节例外保留的原生回归检查。未经这些检查，计划状态不提升为已验证。
