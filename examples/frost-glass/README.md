# 原生玻璃霜边

`frost-glass.pptx`为四页制作样稿：清晰原图、可编辑的原生Blur30参考、两个玻璃窗口、移动后的窗口。背景使用PowerPoint原生生成的模糊缓存；窗口以真正的幻灯片背景填充共用画面坐标，叠白色20pt、零偏移内阴影形成霜边。

诊断图案由本地生成，便于看清模糊、位置和边界；不是业务内容模板。用于实际演示时，应同步替换原图、模糊参考和背景缓存，重新预览。原生模糊参考与窗口样式可编辑，缓存需重新生成，不是实时背景模糊。

`preview.png`是原生导图；`playback.mp4`为本机PowerPoint的23秒实际放映，覆盖进入、移动位置页和返回。已独立核对模糊程度、共享坐标、内侧高光衰减与保存重开；本例无动画，也不代表Hover或Morph组合已通过。

重建沿用[局部模糊制作链](../../officecli-ppt-design/references/local-blur-background.md)，给build与verify加`--frost`，其余步骤保持原调用。使用本机已有工具，不下载素材。
