# 指定媒体触发

[可编辑PPTX](media-shape-triggers.pptx) · [原生播放](playback.mp4)

点击蛋糕主体显示循环烟花GIF，点击HAPPY BIRTHDAY标题让纸屑视频从顶部飞入、同时播放并以70%透明度叠在背景上。两个入口彼此独立。第二页使用同一段视频省去透明效果，可直接比较。

蛋糕、标题和背景由可编辑原生对象组成；GIF和视频真实嵌入，可替换。烟花与纸屑为原创媒体素材，蜡烛为静态装饰。视频长12秒，GIF长2.4秒并无限循环。

播放文件拼接两个独立原生片段：主场景36秒、不透明对照20秒。最终稿保存关闭重开后，以七次实际点击测试空白、蛋糕、标题和播放中的空白；输入日志无额外操作，30个分布帧已复看。GIF隐藏/显示与多轮动态、视频飞入和播放、实际背景透出均已确认，OfficeCLI验证零错。

多触发组的编排顺序、曾发生的归属冲突及制作入口见[媒体指定触发指导](../../officecli-ppt-design/references/media-shape-triggers.md)。本例未验证任意跳返、精确GIF首帧或重复点击标题的全部状态。字体为Noto Sans SC与Arial。
