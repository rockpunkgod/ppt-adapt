# 把团队信号，连接到下一步行动

`curve-links.pptx`是一页可编辑的定性关系图：观察连接探索、反馈连接响应、复盘连接优化。三条平滑曲线用四个线条色标衔接两端类别色，前景线通过原生下投影区分交叉，六个圆形节点覆盖线端。线宽不代表数量。

曲线、线条渐变、阴影、文字和节点均为原生PowerPoint对象。已在本机PowerPoint查看、静态放映8秒，并确认保存重开画面一致；另在副本上实际移动末端确认可编辑。`preview.png`为原生导图，`playback.mp4`为静态放映录像，本例没有动画。

复用既有[曲线制作入口](../../officecli-ppt-design/references/layout-story-geometry.md)，运行`layout_story_geometry.py --recipe curve-links`，传入本机OfficeCLI与新输出目录即可重建，不需要下载素材。更换节点位置时同步调整曲线端点、控制柄和叠层；多路径、定量流量、动态交互需按需求另行制作与预览。
