# BOLD：让标题进入椭圆顶盖

`ellipse-cap.pptx`包含四页：原始可编辑文字、原生字形轮廓、两端收尖的椭圆顶盖，以及原正高度带状映射的比较。顶盖由椭圆上弧与浅弯刀线分割而成，两端高度精确为零；映射后的四个字母和四个字孔均保留。

字形结果是可编辑矢量轮廓，改字从第1页备份重新制作；它不是实时字体或Adobe实时包络。使用现有`envelope_band_*`制作链，加`--ellipse-cap`即可重建，详见[制作指导](../../officecli-ppt-design/references/bounded-envelope.md)。无需下载字体或素材，本例使用Arial Bold。

`preview.png`为第3页原生导图；`playback.mp4`为本机PowerPoint的23秒实际播放，覆盖原稿、轮廓、顶盖、比较页及返回。结构、真实字孔与可读性分别核对；本例没有动画，也不代表任意形状、中文或其他字体已通过。
