# 点击停转与相位保持

[可编辑PPTX](until-next-click.pptx) · [原生播放](playback.mp4)

第一页单击启动转盘，再次单击停在当前角度并显示状态；左方向键两次回退后可以重新开始。第二页作对照：同样的两次点击显示文字，转盘继续旋转。四个扇区、字母、相位点和状态文字都是可编辑对象，停止角由实际点击时刻决定。

原生播放文件拼接了两个独立片段：32秒的两轮停转/回退，以及15秒的持续旋转对照。八次实际输入、24个分布帧及逐帧相位已检查；停转后的角度稳定，对照页显示状态后仍持续转动。文稿通过OfficeCLI验证。

状态文案为预置说明，未识别落在哪个分区。字体需要Noto Serif SC、Noto Sans SC与Arial。制作方法和测试边界见[点击相位指导](../../officecli-ppt-design/references/until-next-click.md)。
