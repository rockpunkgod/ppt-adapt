# 看见信号，才能向前

三页原创演示：清晰场景、虚化降亮度对照、六笔揭示。真实幻灯片背景保存清晰图，六个可编辑笔刷轮廓透出相同位置的内容；每笔交替擦入，最后淡入标题。

主体使用OfficeCLI，PowerPoint COM补充原生Blur30、亮度−54%、背景填充及500ms Wipe/Fade。笔刷不是PNG裁片，图像不会分别拉伸到每个刷头。可复现命令见[制作指导](../../officecli-ppt-design/references/local-blur-background.md)；`assets`提供原创场景和生成源，只需本机Pillow，不下载素材。

`playback.mp4`为最终PPTX的45秒实际播放，9次方向键、0额外输入。两轮均一次Right启动六笔和标题，Left先撤回，再按Left返回，重进后重新隐藏。36个笔刷中间态、标题渐显和四个隐藏状态已核；46个画面已复看，保存重开三页画面一致。`preview.png`为第3页原生导图。

范围限本例轮廓、布局和上述操作路线。共享背景图在原图颜色边缘有少量重采样差异，坐标对齐通过，不能声称与清晰参考像素完全相同；新图片、刷头或快速打断应实际预览。
