# LUMA：让每一个重点，都被看见

三页原创演示，依次聚焦感知、判断和响应。真实可旋转的GLB灯具、原生三段透明渐变光束、图片与圆形的原生相交和1.5秒Morph组合使用；文字、模型、光束和裁形均可编辑。光束是二维模拟，不是体积光或真实照明求解。

`assets`内附原创模型、背景及生成源。`make_assets.py --outdir NEW`只需本机Pillow，不下载素材。制作复用[3D场景指导](../../officecli-ppt-design/references/model3d.md)内的两步组合命令；当前校准只适用于这个带橙色灯口、轴向为+Y的原创灯具，换模型需重新定位投影锚点。

`playback.mp4`是27秒本机PowerPoint实际播放：1→2→3→2→1→2，5次方向键、0额外输入。21个分布画面包括转场中间态已复看；三页保存重开后逐像素一致。`preview.png`为第1页原生导图。组合通过范围仅此三页与这条播放路线，不外推任意模型、快速中断或真正3D光照。
