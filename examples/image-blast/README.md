# 保留信号，释放噪声

四页可编辑演示，从通道偏移、局部大风拖尾、双层冷暖叠加，推进到标题应用。图像为项目已有原创诊断素材；没有下载作者照片。

`image-blast.pptx`由OfficeCLI制作，实际Photopea Blast及两个独立Overlay图层生成效果素材。文字和图片位置可编辑，第2页底图与透明条带保持独立；外部滤镜本身不在PowerPoint内实时计算。`assets`保留底图、条带输入/输出、两张画笔和实际最终合成图。[制作方法](../../officecli-ppt-design/references/image-blast-overlay.md)沿用已有配方，不改变旧拖线近似示例。

`playback.mp4`为本机PowerPoint窗口放映27秒，6次物理方向键，前进、返回、再次进入均到达预期页；7个实播状态已复看。保存重开四页原生导图像素相同，原始图片嵌入字节保持，文字无溢出。`preview.png`为第4页原生导图。

当前验证限此静态组合，不包含动态故障闪烁、Adobe算法像素等价或任意新素材的适配。
