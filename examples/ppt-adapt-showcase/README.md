# PPT Adapt：让 Agent 做出值得上台的 PPT

[打开可编辑演示](ppt-adapt-showcase.pptx)，使用桌面 PowerPoint 放映。

12 页完整项目介绍：项目定位 → 理解表达目的 → 组织内容 → 制作能力 → 视觉焦点 → 可编辑交付 → 使用场景 → 结束主张。作品以自身的设计与播放效果展示项目价值，不附效果目录或案例实验室。

暖白与炭黑构成主线，紫色与橙色承担强调；大字号文字、关系图、展开画面、真实图表、连续聚光场景形成不同的页面节奏。复用项目已有的文字切片、曲线路径、Morph、原生图表分步呈现、图表渐变、3D灯具与光束、逐字Wave等机制。图表保留真实嵌入工作簿，33/1/47/5来自仓库配方索引的四类后端条目。

页面不放声明性小字。文字、图表、形状、模型及时间轴保持可编辑。聚光场景的光束使用原生二维渐变；背景图像保留其素材属性。

`playback.mp4`由本机 PowerPoint 原生播放的两段录屏合成，覆盖全稿；不是自动导出的视频。此次组合的播放范围以这份成品为准，不代表所有配方的任意组合均已验证。
