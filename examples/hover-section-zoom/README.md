# Hover / Section Studio

`hover-section-zoom.pptx`是7页可编辑演示。把鼠标移到A或B卡片，图标缩小并出现章节预览；点击预览，浏览两页正文；章节结束后返回预览，移出卡片回首页，再次进入仍可正常播放。

内容分为Research与Delivery两条线，采用米色背景、薄荷色状态提示和三种步骤色，正文保持相同的阅读顺序。悬停Morph为0.35秒、章节Zoom为0.5秒，正文用Uncover转场。使用真实双孔形状及原生Section Zoom，文字、卡片和正文均可编辑。

`playback.mp4`为最终文件约71秒本机PowerPoint连续播放：两分支各两轮、25个状态、12次真实点击，包含第二页及节末返回；`preview.jpg`展示主要状态和过渡。该组合独立实播通过，没有借用原单页Slide Zoom的结论。

重新制作先运行已有[Hover Zoom三步制作链](../../officecli-ppt-design/references/hover-zoom-menu.md)，再使用[多页章节适配步骤](../../officecli-ppt-design/references/hover-section-zoom.md)。保留所有幻灯片放映模式；测试不覆盖快速连击、Kiosk或任意章节结构。
