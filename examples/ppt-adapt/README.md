复用已有OfficeCLI主体制作、原生自定义几何、字体层级、连续对象Morph和COM精修机制。全稿9页；主要连续段为第1–3、4–6和7–9页，章节间用柔和淡化。字体为Noto Serif SC、Noto Sans SC及Bahnschrift SemiCondensed，跨机需保留字体或替换后检查折行。
