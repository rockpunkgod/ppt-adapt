[可编辑PPTX](ppt-adapt.pptx) · [整套预览](preview.jpg) · [原生实播](playback.mp4)

九页介绍以纸白、朱橙、雾绿和灰紫构成视觉语言，衬线标题配合无衬线正文。从一句需求出发，把内容整理成观看路线，再进入原创“漫游”城市步行提案：全景建立位置，中景沿路线推进，近景停在书店。回到已完成的RoboMaster作品展示不同主题的表达，最后落到可编辑交付和使用入口。页面没有声明性批注；封面与尾页按要求署名“made by codex with ppt adapt”。

制作先比较城市场景与冷色编辑台两个方向，选择更适合本次表达的城市场景；优先完成第4–6页的连续片段，并原生实播检查，再扩展整套。高潮来自沿路线抵达具体细节，文字阅读层保持稳定，章节之间用柔和淡化留出停顿。

漫游是本次原创概念提案，不是已上线工具、真实城市地图或导航实测。建筑、河道、树木、路线和主要文字由PowerPoint原生形状、路径与文本构成；近景仍使用同一组对象。第7页使用本次原生导图与本仓库已完成的RoboMaster作品预览，非竞品或客户成效对照；原照片来源保留在技能的`assets/demo/robomaster-sources.md`中。二维投影和Morph不称为真实三维摄像机，必要身份说明在备注中。

复用已有OfficeCLI主体制作、自定义几何、字体层级、连续对象Morph及COM精修机制，不新增制作引擎。字体为Noto Serif SC、Noto Sans SC和Bahnschrift SemiCondensed；跨机需保留字体或替换后检查折行。

双击仓库根目录的[一键重建入口](../../rebuild-demo.cmd)可从本地源重建当前作品及原生预览。内部源位于`officecli-ppt-design/scripts/demo_source/`；重建不下载素材，新需求仍独立构思。

当前交付完成九页原生预览与43秒连续实播，8次真实前进键覆盖全稿。检查文字溢出、全景到书店的中间态及章节衔接；[播放记录](native-playback.json)绑定当前PPTX和实播视频，结论限于本次作品与路线。
