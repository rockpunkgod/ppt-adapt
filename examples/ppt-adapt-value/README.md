# PPT Adapt：从一段需求，到完整发布

[可编辑PPTX](ppt-adapt-value.pptx) · [原生实播](playback.mp4) · [整套预览](preview.jpg)

本机可双击仓库根目录的[一键重建入口](../../rebuild-demo.cmd)，从随附制作源重新生成这套十页演示及原生预览；无需重新下载素材。Agent内部使用说明见[重建说明](../../officecli-ppt-design/references/rebuild-demo.md)。

PPT Adapt是一套将整套演示的设计与制作方法接入Agent的Skill。这份10页介绍用一次实际制作任务说明项目的价值：从一段边缘AI模块的演示需求，做出三页连贯的AURA概念产品发布，再展示另一种艺术方向、可编辑图表、真实制作链和可接手的交付文件。重点放在完成的作品与具体使用结果，技术说明在其后解释成果如何实现。

AURA是本次原创概念任务，不是客户案例或在售产品。第3–5页是可独立使用的三页发布示范，主视觉、工作方式与应用场景围绕同一产品组织；同一PNG图片以原生Morph进行位移与等比缩放。产品图是原创生成素材，不把它描述成可直接旋转的GLB模型。正文与案例页文字、形状、图表及时间轴保留PowerPoint原生对象；封面和对照页使用本次成稿的导图作为展示图片。

第7页复用项目已有、带真实嵌入工作簿的原生图表，以本次视觉方向重新排版。33/1/47/5来自项目配方索引。测试副本实际将Hybrid对应单元格47改为60，原生图表随之更新；交付成品保留原始47，未编造产品性能数据或AI效率比较。

制作继续使用OfficeCLI、PowerPoint COM及原生PowerPoint。复用已有图片构图、连续对象Morph、原生图表与工作簿绑定机制，没有增加PPT引擎、评分系统或组合专用Skill。字体为Noto Sans SC、Noto Sans SC Black、Bahnschrift SemiCondensed与Noto Serif SC；跨机缺字时应安装字体或替换后检查折行。

产品主视觉及内置imagegen提示词见[素材说明](assets/README.md)。页面没有声明性小字或效果目录。

已完成最终文件的55秒本机PowerPoint连续实播：9次真实前进按键、无额外输入，覆盖全部10页；复看了两段Morph的开始、中间与结束，以及全稿衔接。原生逐页预览未发现文字框溢出，文件结构与图表工作簿检查通过。结论仅适用于本次成品与该播放路线。
