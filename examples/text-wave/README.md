# 逐字波浪

[可编辑PPTX](text-wave.pptx) · [原生播放](playback.mp4)

四页展示0.5秒逐字Wave、2秒慢放、增大竖向位移与静态对照。每页都保留一个可编辑的DESIGN文本框，运动同时包含原生起伏和逐字旋转；没有拆字、GIF或视频代播。

从头放映，每页单击开始循环，用右方向键切换。字母延迟10%，所以六字母的整词周期约为0.75秒或3秒，比动画面板的0.5秒或2秒更长。

最终文件经本机PowerPoint保存关闭重开，44秒实际放映覆盖三种运动和静态页，20个分布帧已复看。逐帧轨迹确认字母错峰、持续循环、幅度差异和静态对照；另核实原生文本、往返路径、四段旋转及父节点循环，OfficeCLI验证零错。前一次原型因前台切换停止，未计通过。

需要Noto Serif SC、Noto Sans SC与Arial。制作入口和适用边界见[逐字Wave指导](../../officecli-ppt-design/references/text-wave.md)。本例不承诺任意字数、跨页返回重启或UntilNextClick停止语义。
