# 笔尖与墨迹同步

[可编辑PPTX](ink-pen-sync.pptx) · [原生播放](playback.mp4)

两个内容页分别展示5秒慢放和1秒书写。笔尖围绕透明辅助圆的中心沿原生墨迹移动；快放串联0.5秒入场、1秒Replay/路径与0.5秒向左离场。文字、铅笔组合和真正Ink对象均可编辑，没有用图片或Wipe代替墨迹。

从头放映后单击空白开始，使用右上角“5秒/1秒”切换。另有两个隐藏的0秒复位过渡页，令再次进入时重新初始化动画；保留文稿的“使用计时”设置，导航链接应指向过渡页。按普通顺序额外点击仍可离开内容页。

最终文件保存关闭、重开后完成35秒本机PowerPoint放映，六次实际鼠标点击覆盖慢放、快放与返回后再次快放。20个分布帧已复看。慢放、首次快放、返回快放分别测量146、29、28个绘制中间态，笔尖与独立墨迹末端最大距离约1.43、1.08、1.14毫米；两次快放均完成入场和离场，完整笔迹保持可见。OfficeCLI验证零错。

复用已有InkML构建、Replay时序种子和OfficeCLI页面工具，不重写墨迹循环配方。制作入口与限制见[笔尖同步指导](../../officecli-ppt-design/references/ink-pen-sync.md)。字体为Noto Serif SC/Noto Sans SC。

本例只验证三段等长直线；更换自由手写笔迹时，须同时重配笔迹时间与路径进度，并实际播放。跨机字体和原生动画支持也需确认。
