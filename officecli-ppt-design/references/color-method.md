# 配色：选色系 → 定色值 → 调比例

依据 PPT教练小木《审美无平替，但有方法。》的画面和内嵌字幕蒸馏。时间为原视频时间；下面的色板和 OfficeCLI 映射属于工程示例，不是作者指定参数。

## 1. 选色系：让颜色与语境相符

原视频约 00:35–01:43：颜色联想来自经验与语境；不确定主题该用何色时，参考同类优秀设计并提取色系。不能从“环保常用绿”推导“所有环保汇报只能绿”。优先使用品牌已有色彩约束。

执行时先写三个词，例如“科技 / 克制 / 清晰”，然后选一个主色方向。参考网站或海报的作用是建立颜色关系，不是整页复制。

## 2. 定色值：饱和度与明度共同决定氛围

约 01:47–03:55：广告需要快速抢眼，汇报常需要持续阅读；同一色系也能通过明度、饱和度改变气质。两者应分别判断，降低饱和度不等于简单加黑；没有“所有汇报都要低饱和”的硬规则。

OfficeCLI 接收实际色值。若参考只有截图，采集代表色并记录 HEX；可用标准库 `colorsys` 转换 HLS 后尝试两三个版本，最终回看页面。注意 Python HLS 归一化 0–1，与 PowerPoint 对话框整数尺度不同，不能直接抄数值。

检查正文区实际背景，不只比较色卡。透明面板叠在图片上后，每个位置的对比度都可能不同。

## 3. 调比例：底色大、主色中、点缀小

约 03:55–05:55：同样三种颜色，面积关系不同会改变整体感觉。作者将角色称为“辅色、主色、点缀色”；示例中浅色辅色经常承担大面积背景。**主色这个名称不表示它一定占最大面积。**

把配色映射为：

| 角色 | 用途 | 可执行映射 |
|---|---|---|
| 底色 / 辅色 | 大面积空间、阅读背景 | slide background、浅色面板 |
| 主色 | 主要结构、章节卡片、图表主序列 | shape fill、标题 color、主题 accent1 |
| 点缀色 | 少数重点或状态 | 小标签、重点数据、细线、主题 accent2 |
| 正文色 | 持续阅读 | text color；不默认用主色写所有正文 |

不要把主色铺满全页后，再用浅色细字补救。也不要把每一个图标都涂成不同的点缀色。比较配色方案时保持文案与布局相同，才能观察颜色本身的影响。
