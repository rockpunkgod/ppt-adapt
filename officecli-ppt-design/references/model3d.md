# 原生3D：模型内部动作与跨页场景

来源：[One Skill PPT 3D Morph](https://www.youtube.com/watch?v=3Qo_Hx21KUc)，重点01:51–04:01、05:12–11:10。

## 分清两套动画

Floating、running、waving是GLB中的内部动画；位置、大小、三维朝向的跨页变化是Morph。二维PNG缩放、shape.spin或一个没有动画轨道的GLB不能等价替代。

本轮通过的是**OfficeCLI改造作者公开原生模板，保留3D动画，再用本机PowerPoint确认**，不是从零调用CLI生成库存模型。

## 复现方法

1. 由调用方提供合法取得的含动画GLB的PPTX模板。技能不捆绑完整模板和模型。
2. 使用`build_morph.py --mode 3d-template --source-3d <file> --outdir <new-folder>`改写可编辑文案、备注与字体。
3. 保留model3d、关系、embedAnim、animPr、posterFrame与spTgt；比较模型字节哈希和各页动画结构，不只验证文件中“有.glb”。
4. 同一主体相邻页保留唯一`!!name`，不同内部动作场景可以是不同主体。不要把所有宇航员都改成同一个名字。
5. 屏外模型不做无意义循环；固定页码/导航不随长场景一起滚动。来源在四屏纵向场景中用2秒Morph。
6. 用本机PowerPoint播放，检查内部动作、三维姿态和跨页位移同时成立，并留意卡顿。

## 扩展条件

用户希望从零插入新模型或新增专属3D动画时，检查本机PowerPoint COM/VBA是否暴露对应能力，保留精修脚本与回读证据。若只能通过GUI库存选择或缺少动画资产，报告具体缺口；不编造`scene=`、`animationScene=`等CLI参数。

## 四圆点导航与3D场景组合

同一四页改稿已另做52秒原生鼠标复测：1→4→1→3→2→4→2→3→1，8次点击全部到达预期页，覆盖四个目标、首末跳转、返回与重复进入。复看19个分布帧确认实际页码、圆点高亮、内部模型动作和跨页场景。输入PPTX前后SHA256均为`6d2321b7bf5ce59244191a162b630b7204e0fb177edb64949f007f926c2e0eae`，未改GLB、动作、热点或链接。保留[实际播放](../verification/native-3d-navigation/playback.mp4)与[有限测试结果](../verification/native-3d-navigation/result.json)，完整模板仍由调用方合法提供。

小目标测试时先确认自有放映窗口处于前台，坐标按DWM物理边界和16:9内容区换算，实际物理指针落点属于该窗口。普通箭头模式下，从中性空白区移到目标，再点击；每次等转场结束并核实际页码。测试输入使用真实鼠标，不能以COM跳页、Hyperlink.Follow或Tab+Enter代替。旧定位/焦点分支曾失败；本次没有逐变量隔离全部差异，不把成功归因于一个未经证明的根因，也不据旧失败盲目改正确文件。

此结论只覆盖该四页模板改造及上述路线；新模板、变动的热点/叠层和快速连续点击另验。不把汉堡图标、Explore按钮或任意模型指定触发并入四圆点结果。

## 3D灯具、模拟光束与移动焦点

需要把观众注意力移向多个重点时，可复用图片与圆形Intersect、原生三段渐变三角形、真实GLB和Morph。按暗底图→清晰圆形图片→渐变光束→灯具→文字分层；灯口与光束尖端对齐，光束朝向当前圆形主体。固定标题保持位置，逐页更新短句，不让移动光束压住正文。

来源BV1pa4y117yV 59–131秒（本轮播放量14907）：59/71秒图片与圆相交，77秒显示焦点，89秒选择库存照明模型，101/107秒三角形与线性270°三光圈，113秒模型置顶，119–125秒复制并调整灯具姿态、光线位置，131秒演示结果。Ego Lite实际复核13个视频元素画面。这是**真实3D灯具加二维渐变光束**，不能按原先宽泛笔记误写成真实体积光课程。

`lamp_focus_build.py`沿用现有OfficeCLI Deck机制制作三页；`lamp_focus_polish.ps1`沿用COM MergeShapes完成真圆形图片，并对齐投影锚点，后端为**hybrid**。无需新引擎。当前原创灯具沿+Y发光，橙色灯口用于定位；先给X轴25°使端面可见，再按目标改变Z朝向。正侧视端面没有面积，不能从不可见灯口推断锚点。模型自动适配的投影范围随姿态变化，单靠对象边框中心对齐会错位。

```powershell
python scripts/lamp_focus_build.py --officecli EXE --image LOCAL_SCENE.png --model ORIGINAL_LAMP.glb --outdir NEW_BASE
powershell -File scripts/lamp_focus_polish.ps1 -InputDeck NEW_BASE/lamp-focus-base.pptx -OutputDeck NEW_FINAL.pptx
```

校准器对当前原创资产的橙色端面做原生投影定位，找不到端面时停止，不替任意模型猜测灯口。三段透明度及光圈位置可在PPT内调整。更换模型或页面尺寸后重新确定轴向、端面位置和光束透视；换图片也需重做圆形裁切，不能把旧裁图当作动态背景采样。

[原创三页作品与27秒播放](../../examples/lamp-focus/README.md)附原始GLB、背景与资产生成源；无需作者模板或下载。当前样稿使用1.5秒Morph，三个静态灯口与尖端误差均小于2个1600宽导图像素。包内真GLB字节保持、三stop alpha及相交后四段圆形曲线已核；保存重开画面零差。实际5次方向键走1→2→3→2→1→2，0额外输入，21个静止/运动画面复看后确认焦点移动及返回正常。此实播是本组合自己的证据，不借独立Morph或3D效果通过结果升级。它不证明物理照明、任意新模型或快速打断下的连续性。
