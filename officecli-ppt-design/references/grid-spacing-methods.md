# 网格、间距与信息主次

工程类别：`officecli-native`。来源为 [50P版式课程](https://www.bilibili.com/video/BV1oPHgeiEgb/)，按父BV播放量筛选。完整研究在工作区distill/bilibili-long-design；本页只收已制作并用本机PowerPoint检查的代表机制，不宣称课程全部海报效果已复现。

## 基础动作

1. 将真实文案分成结论、支持信息、条件/来源三个角色。主次由沟通目标决定，不由字符串长度决定。
2. 先确定画幅和版心，再定义列宽/栏距/行锚点。用共享边线定位文本组，不强行令所有对象居中；光学字边可能不同于文本框边。
3. 给标题足够字号与笔重，让正文成组。组内间距小于组间，三档间距形成节奏。辅助圆形可作间距尺，交付时删除；不用固定海报行距比值。
4. 通过面积、笔重、对比和距离平衡。大数字与解释不必相等宽；数字和汉字的字体替换后检查实际基线与占位。
5. 将分散元素用轮廓或少量线条串联。线若表达数据关系必须有依据，静态视觉导线不称轨道动画。
6. 同一份内容可先后强调时间、主题或身份，从而生成不同排法。每版仍保留所需内容与统一对齐锚点。
7. 将语义方向转为箭头/刻度等辅图时，区别真实数据和装饰；不靠虚构销量、推荐人或日期填空。
8. 通过重复类别模块统一标题/说明/标记/间距。背景弱化年份仅装饰，关键截止日期另设高对比文本。

## 可执行样例

```text
python scripts/build_layout_methods.py --officecli officecli --out ./output/layout-methods.pptx
```

脚本依赖同目录build_components.py，均为标准库编排OfficeCLI；新建8页，拒绝覆盖已有文件。页面对应源P03/P05/P06/P07–09/P45–47，全部文字与形状可编辑。图像抠图、逐笔造字、PS正片叠底和2.5D不在这8页中，不能据此称那些能力已通过。

## 原生验证与修复

首版原生PowerPoint全页检查发现箭头压住标题、个别框高度不足。修版增加必要高度并移开箭头；复验无文字溢出，文字层级与组块保持清楚。修改内容后仍应按实际字体/换行重新验收，不能只检查原样例。

验证采用本机PowerPoint导出PNG，另生成原生影片；静态方法不需要编造运动轨迹测试。示例中可见网格/标尺属于教学标记，正式交付可以隐藏。原课程以AI/PS/海报设计为主，其快捷键和毫米/像素数值不能直接解释为PPT命令与字号；“超过5字必须换行”“毛笔字不能作标题”等作者偏好不收为通用规则。
